# Pentaract Registration Guide: DB & Tokens

This guide explains how to set up your distributed storage infrastructure within the Pentaract platform.

---

## 0. Setting up the Telegram Backend (Groups/Channels)
Pentaract uses Telegram chats as storage buckets. You need to create these first.

### How to Create a Storage Chat:
1. **Create:** In Telegram, go to `New Group` or `New Channel`.
2. **Name it:** Use something clear (e.g., `Pentaract_Node_01`).
3. **Add Bot:** Add your Pentaract Telegram Bot as an **Administrator**.
4. **Get ID:** 
    - Send a message in the chat.
    - Forward that message to `@GetIDsBot` or `@userinfobot`.
    - Copy the **Chat ID** (it must start with a minus sign, like `-100123456789`).

---

## 1. Prerequisites
Before you begin, ensure you have:
- **Telegram Chat ID:** A unique identifier for the Telegram chat where files will be stored. Note that this must be a **negative integer** (e.g., `-100123456789`).
- **Worker Token:** A secure token generated by your storage worker instance.

---

## 2. Registering a Storage (DB)
The "Storage" acts as the logical database/container for your files on Telegram.

### Steps:
1. Navigate to the **Drives** dashboard.
2. Click the **"Register Drive"** button (top right).
3. **Name:** Give your drive a descriptive name (e.g., "Primary Backup").
4. **Chat ID:** Enter your Telegram Chat ID. 
    > [!IMPORTANT]
    > Ensure the ID is negative. If you are using a bot, make sure it has permissions to post in that chat.
5. Click **Register**.

---

## 3. Registering a Storage Worker (Token)
Workers are the "engines" that perform the actual file operations using the provided tokens.

### Steps:
1. Navigate to the **Workers** section (via the sidebar or menu).
2. Click **"Register Worker"**.
3. **Name:** A unique name for this worker (e.g., "Node-01-Asia").
4. **Token:** Paste the secure token provided by your worker software.
5. **Storage:** Select which Drive (DB) this worker should be assigned to.
6. Click **Register**.

---

## 4. Verifying Connectivity
Once both are registered:
1. Go back to the **Drives** dashboard.
2. Click on your newly created Drive.
3. Try creating a folder or uploading a small test file.
4. If successful, your distributed storage is now fully operational!

---

### Troubleshooting
- **Unauthorized Error:** Double-check your worker token.
- **Upload Failed:** Ensure the Telegram bot associated with the chat ID is online and has sufficient permissions.
- **Empty File List:** If you just registered, it may take a few seconds for the initial scan to complete.
